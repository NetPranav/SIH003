# Smriti-NER Static & Cultural Assets Repository
**Sub-Phase 3.1 Deliverable**: Monorepo Cultural Assets Index  
**Problem Statement ID**: 26003 (SIH 2026 — MDoNER)

## Asset Directory Layout
- `/audio`: Native folk instruments (Assamese Pepa, Manipuri Pung, Khasi Duitara, Tripuri Kham, Bodo Sifung)
- `/textiles`: Vector SVG pattern motifs (Muga Mekhela, Dokhona, Jainsem, Puanchei, Rignai, Leirum)
- `/fauna`: Cultural conservation wildlife illustrations (One-horned Rhino, Sangai Deer, Red Panda, Hoolock Gibbon, Mithun, Hornbill)
- `/icons`: High-contrast WCAG 2.2 AAA 2.5px stroke geriatric vector icons
- `/fonts`: Open-source multilingual font specimens for Assamese, Meitei Mayek, Devanagari, and Latin
